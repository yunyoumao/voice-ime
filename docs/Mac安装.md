# 语音输入法 · Mac 安装指南

> 这是**未签名**版本（没买 Apple 开发者证书），所以**首次打开要手动放行一次**，之后就正常用了。

## 一、放行 App（首次必做）

把 `VoiceInput.app` 放进「应用程序」，然后**二选一**：

**方法 A（推荐）**
1. 在 `VoiceInput.app` 上 **右键 → 打开**
2. 弹窗点「**打开**」
   （直接双击会被拦、没有「打开」按钮；**右键**打开才有）

**方法 B（一条命令，最省事）**
打开「终端」，粘贴回车：
```bash
xattr -cr /Applications/VoiceInput.app
```
之后双击即可正常打开。

> 若提示「**已损坏，应移到废纸篓**」——这不是真的损坏，是 Gatekeeper 拦未签名 App，用**方法 B** 即可解决。

## 二、授权三项权限（macOS 硬性要求）

语音输入要监听热键、模拟粘贴、录音，需到
**系统设置 → 隐私与安全性** 给 `VoiceInput` 勾上这三项：

| 权限 | 用途 |
|---|---|
| **麦克风** | 录音做语音识别 |
| **输入监控** | 监听全局热键（右 Shift 开转盘等） |
| **辅助功能** | 模拟 Cmd+V 把识别结果上屏 |

> ⚠️ 勾选后**彻底退出 App 再重开**——权限改动要重启进程才生效。

## 三、首次启动

- 首启会自动下载本地识别模型（约 **520MB**）到
  `~/Library/Application Support/VoiceInput/models`，等进度条走完即可（只下一次）。
- 之后：说话 → 识别 → 自动上屏到当前光标处。
- 默认热键：右 Shift 按住开转盘选模式，松开锁定继续说，再按停止上屏。

## 四、润色 / 翻译（可选，默认走本地）

默认用**本地 Ollama**（离线、不耗流量、零成本）。启用方式：
1. 装 [Ollama](https://ollama.com/download/mac)
2. 终端跑：`ollama pull qwen2.5:7b`

不想装本地模型？打开**设置**（菜单栏托盘图标 / 按 F9），把「大模型通道」切成
**智谱直连**（填个 API key）即可联网润色。

## 常见问题

- **双击没反应 / 提示已损坏** → 见上「放行 App · 方法 B」。
- **能听到在录音但不出字** → 多半是「辅助功能」没勾 VoiceInput；勾上后**重启 App**。
- **几乎没收到声音** → 检查「麦克风」权限 + 设置里选对输入设备（可用设置里的实时电平测一下）。
- **润色很慢/失败** → 本地 Ollama 没启动或没 `pull` 模型；或在设置里切到智谱直连。
